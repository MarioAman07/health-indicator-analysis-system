# API Examples

**Status:** design draft (DIP-14) — the API is not implemented yet  
**Last updated:** 21 Oct 2026  
**Related:** [requirements](../06-requirements.md) · [architecture](../07-architecture/architecture.md)

All values below are **illustrative**: they show the format of requests and responses, not real patients or model results.

- Base path: `/api/v1`
- Format: JSON; the OpenAPI description is generated by FastAPI at `/docs`.
- Variable names follow the PhysioNet/CinC Challenge 2019 columns; a missing measurement is `null`.
- Every response that contains a risk also contains `disclaimer` (NFR-06).

## Endpoints

| Method and path | Purpose | Requirements |
|---|---|---|
| `GET /api/v1/health` | Service status | NFR-05 |
| `POST /api/v1/predict` | Risk for a patient history up to a given hour | FR-06, FR-07, FR-10, FR-11 |
| `GET /api/v1/patients` | Demo patients with current risk and alert state | FR-08 |
| `GET /api/v1/patients/{patient_id}/timeline` | Hourly measurements and risk of one patient | FR-09 |
| `GET /api/v1/patients/{patient_id}/predictions` | Stored predictions of one patient | FR-12 |
| `GET /api/v1/models/current` | Metadata of the model in use | FR-14 |

## POST /api/v1/predict

### Request

```json
{
  "patient_id": "demo-02",
  "as_of_hour": 40,
  "measurements": [
    {"hour": 0,  "HR": 83.0, "O2Sat": 97.5, "Temp": 36.9, "SBP": 121.0, "MAP": 81.0, "DBP": 63.0, "Resp": 15.0, "WBC": 9.8, "Lactate": null},
    {"hour": 1,  "HR": 85.0, "O2Sat": 97.0, "Temp": null, "SBP": 119.0, "MAP": 80.0, "DBP": 62.0, "Resp": 16.0, "WBC": null, "Lactate": null},
    {"hour": 40, "HR": 91.6, "O2Sat": 95.2, "Temp": 37.8, "SBP": 108.0, "MAP": 70.5, "DBP": 55.0, "Resp": 21.0, "WBC": null, "Lactate": 2.1}
  ]
}
```

Only measurements at hours ≤ `as_of_hour` are used (FR-02). Columns not sent are treated as not measured.

### Response 200 — risk available

```json
{
  "patient_id": "demo-02",
  "as_of_hour": 40,
  "state": "ok",
  "risk_score": 0.74,
  "risk_level": "high",
  "threshold": 0.30,
  "alert": true,
  "alert_suppressed_until_hour": 45,
  "top_features": [
    {"feature": "Resp_last", "label": "Respiratory rate, last value", "value": 21.0, "contribution": 0.31},
    {"feature": "Temp_last", "label": "Temperature, last value", "value": 37.8, "contribution": 0.22},
    {"feature": "MAP_last", "label": "Mean arterial pressure, last value", "value": 70.5, "contribution": 0.15},
    {"feature": "HR_mean_6h", "label": "Heart rate, mean of last 6 h", "value": 90.2, "contribution": 0.09},
    {"feature": "O2Sat_last", "label": "Oxygen saturation, last value", "value": 95.2, "contribution": 0.05}
  ],
  "hours_since_vitals": 0,
  "model_version": "lgbm-v0.1.0",
  "disclaimer": "Research prototype — not a diagnosis."
}
```

### Response 200 — insufficient data (FR-11)

```json
{
  "patient_id": "demo-05",
  "as_of_hour": 53,
  "state": "insufficient_data",
  "risk_score": null,
  "risk_level": null,
  "alert": false,
  "hours_since_vitals": 7,
  "message": "Key vital signs have not been measured for more than 4 hours.",
  "model_version": "lgbm-v0.1.0",
  "disclaimer": "Research prototype — not a diagnosis."
}
```

### Response 422 — invalid input (FR-06, NFR-09)

```json
{
  "detail": [
    {"loc": ["body", "measurements", 2, "HR"], "msg": "Input should be a valid number", "type": "float_parsing"},
    {"loc": ["body", "as_of_hour"], "msg": "Input should be greater than or equal to 0", "type": "greater_than_equal"}
  ]
}
```

## GET /api/v1/patients

```json
[
  {"patient_id": "demo-02", "icu_hour": 71, "risk_score": 0.97, "risk_level": "high", "alert": true, "hours_since_vitals": 0},
  {"patient_id": "demo-05", "icu_hour": 53, "risk_score": null, "risk_level": null, "alert": false, "hours_since_vitals": 7}
]
```

## GET /api/v1/patients/{patient_id}/timeline

```json
{
  "patient_id": "demo-02",
  "hours": [
    {"hour": 0, "HR": 83.0, "Temp": 36.9, "Resp": 15.0, "MAP": 81.0, "O2Sat": 97.5, "risk_score": 0.05, "alert": false},
    {"hour": 1, "HR": 85.0, "Temp": null, "Resp": 16.0, "MAP": 80.0, "O2Sat": 97.0, "risk_score": 0.06, "alert": false}
  ]
}
```

## GET /api/v1/patients/{patient_id}/predictions

```json
[
  {"created_at": "2026-11-20T10:15:02Z", "as_of_hour": 40, "risk_score": 0.74, "alert": true, "state": "ok", "model_version": "lgbm-v0.1.0"}
]
```

## GET /api/v1/models/current

```json
{
  "model_version": "lgbm-v0.1.0",
  "model_type": "LightGBM",
  "trained_at": "2026-11-15T12:00:00Z",
  "config_hash": "9f2c1e7",
  "threshold": 0.30,
  "suppression_hours": 6,
  "insufficient_data_hours": 4,
  "validation": {"auroc": 0.0, "auprc": 0.0},
  "library_versions": {"lightgbm": "4.5.0", "scikit-learn": "1.5.2"}
}
```

`validation` values are placeholders until the model is trained.

## Command line

|---|---|---|
| `make install` | Install pinned dependencies | available |
| `make eda` | Data analysis → `docs/02-evidence/eda-summary.json` and figures | available |
| `make test` | Run automated tests | available |

| `make api` | Start the backend: `uvicorn src.backend.main:app` | planned (FR-06) |
| `make ui` | Start the dashboard connected to the API | planned (FR-08 – FR-13) |
